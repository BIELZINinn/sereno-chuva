# Sereno — APK Android

**Sereno** — chuva para dormir.

- Pacote: `app.sereno.chuva`
- Versao: 1.0.5
- Min SDK: 24 (Android 7)
- Arquivo: `Sereno.apk`

## Instalar

1. Copie `Sereno.apk` para o celular.
2. Abra o arquivo e permita instalar de fontes desconhecidas.
3. Abra **Sereno** na gaveta de apps.

O som continua com a tela bloqueada. Use o timer para desligar a noite.
