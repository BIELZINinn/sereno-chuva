# Sereno

Chuva, trovões e noites calmas para pegar no sono.

App mobile de sons para dormir: misture chuva, tempestade, raios, telhado, lareira e mais. Tem timer até um horário, fade e modo segundo plano.

## APK Android

Baixe e instale:

`apk/Sereno.apk`

- Nome do app: **Sereno**
- Pacote: `app.sereno.chuva`
- Versão: 1.0.0
- Android 7+ (API 24)

No celular, permita instalar de fontes desconhecidas e abra o arquivo.

## Web

Abra `index.html` ou sirva a pasta com qualquer servidor estático.

```
python3 -m http.server 8000
```
